MiX Stream Recorder

Record your screen + webcam into one small video. Free. Offline. No account.

Get the app

Download for Windows (ZIP) All releases

Unzip anywhere. You do not need a GitHub account.

First time on this PC (once)

  1. Python — Download Python and tick Add python.exe to PATH during install.
  2. ffmpeg — open PowerShell and run:
    winget install Gyan.FFmpeg
    then close that window.

Every time after that

1 Double-click run.bat
2 Start preview → Record → Stop
3 Open the recordings folder for your MP4

What you get

ScreenOne monitor or both
WebcamOptional PiP or side-by-side
OutputOne normal MP4 (kept lean so files stay small)
Example~5 minutes ≈ ~23 MB on Lean quality

Not working?

  • python not found → reinstall Python with PATH ticked
  • Encode errors → install ffmpeg, open a new window, run again
  • No camera → use Screen only, or Rescan devices after plugging in
