# Security

MiX Stream Recorder is a **local** desktop utility.

- It does not open network ports or phone home.
- It may access **screen content**, **camera**, and write files under `recordings/`.
- Dependencies: Python packages in `requirements.txt` + system **ffmpeg**.

If you find a vulnerability in this project, open a GitHub issue or contact the maintainer privately. Please do not file public issues that include personal screen captures.
